**شاخه:** `main`

## تکمیل‌شده در نسخه 2.3.2

- پنل مستقل ورزشکار و ثبت گزارش پیشرفت تمرین
- ثبت‌نام OTP و تأیید شماره موبایل
- خرید فقط با حساب ورزشکار احراز‌شده و شماره پرداخت تأییدشده
- Idempotency برای درخواست‌های Checkout و جلوگیری از تراکنش تکراری
- مدیریت Callback درگاه، بازیابی پرداخت دیرهنگام و مسیر reconciliation
- تقویم رزرو مشاوره و جلوگیری از رزرو تکراری
- پیام خصوصی مربی و ورزشکار
- صف پیامک رزرو با رسید ارائه‌دهنده و عدم ارسال مجدد خودکار در وضعیت مبهم
- مدیریت فایل خصوصی و پشتیبان‌گیری رمزگذاری‌شده

## اصلاح امنیتی جدید در 2026-11-22

- خروجی گرفتن از Backup قبلاً می‌توانست بدون رمزگذاری انجام شود، چون کلاینت پارامتر `encrypted` را نمی‌فرستاد.
- API اکنون همیشه خروجی را با AES-256-GCM رمزگذاری می‌کند و در نبود کلید اختصاصی fail-closed است.
- کلاینت مدیریت صریحاً خروجی رمزگذاری‌شده را درخواست می‌کند.
- دو assertion رگرسیون برای جلوگیری از بازگشت خروجی plaintext اضافه شده است.
- نسخه URL باندل در HTML به‌روزرسانی شده تا کش قدیمی کلاینت را نگه ندارد.
