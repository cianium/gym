# مرحله چهارم — بررسی یکپارچگی و رفع ناسازگاری ورود

## اصلاح انجام‌شده
- فرم ورود ورزشکار اکنون «شماره موبایل یا ایمیل» می‌پذیرد.
- بک‌اند شناسه ورود را با همان کلید `identifier` دریافت می‌کند و شماره‌های فارسی/عربی و قالب‌های +98/0098 را نرمال می‌کند.
- ورود با ایمیل برای حساب‌های قدیمی حفظ شده است.
- پیام خطای ورود برای شناسه نامعتبر یا گذرواژه اشتباه یکسان است؛ نشست پس از ورود موفق بازتولید می‌شود.

## آزمون‌های انجام‌شده
- `php -l` کنترلر تغییرکرده: موفق.
- ۸ کنترل ایستای سازگاری فرم، API، OTP، نشست و مالکیت: موفق.
- `php artisan test --stop-on-failure`: **متوقف شد**؛ افزونه PHP DOM (`DOMDocument`) در محیط اجرا نصب نیست.

## موارد تأییدنشده / مسدودکننده انتشار
- تست عملی دیتابیس MySQL، مهاجرت‌ها، OTP با پاسخ واقعی ملی پیامک، پرداخت بانکی، نشست در مرورگر و بازیابی نسخه پشتیبان اجرا نشده است.
- پاسخ‌دهی واقعی درگاه پیامک و مدیریت هم‌زمانی درخواست‌های OTP نیازمند تست/بازبینی جداگانه است.
- این نسخه صرفاً اصلاح یک باگ یکپارچگی مهم است، نه گواهی آماده‌بودن انتشار.

## راهنمای تست در محیط دارای افزونه‌ها
1. روی دیتابیس آزمایشی بکاپ بگیرید و مهاجرت‌ها را اجرا کنید.
2. حساب تازه را با OTP بسازید، سپس با همان شماره و رمز وارد شوید.
3. حساب ورزشکار قدیمی را با ایمیل وارد کنید.
4. ورود اشتباه، دسترسی به برنامه دیگران، ثبت گزارش و خروج را بررسی کنید.
5. callbackهای تکراری پرداخت، وضعیت تراکنش و پیامک را جداگانه آزمایش کنید.
