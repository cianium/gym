# وضعیت توسعه پروژه بدنسازی — 2026-11-09

## تکمیل‌شده در این نسخه
- صفحه مستقل `/athlete` برای ورود، مشاهده برنامه‌های منتشرشده و ثبت گزارش تمرین.
- جدول `training_progress` با محدودیت یکتایی گزارش هر روز و هر جلسه.
- API ثبت و مشاهده گزارش با احراز هویت، کنترل مالکیت برنامه و CSRF.
- API مدیر برای مشاهده گزارش‌های یک ورزشکار.
- حفظ کدهای موجود فروشگاه و فرانت‌اند کامپایل‌شده.

## تست انجام‌شده
- PHP syntax بررسی شد.
- `php artisan route:list --path=athlete` با موفقیت مسیرها را شناسایی کرد.

## مواردی که هنوز تکمیل یا تأیید نشده‌اند
- ثبت‌نام عمومی با OTP و اتصال به سرویس پیامک؛ نیازمند کلیدها و محیط واقعی.
- رابط گرافیکی مدیریت برنامه‌ها در پنل مدیر (API موجود است).
- بازسازی سورس اصلی React از خروجی کامپایل‌شده.
- تست دیتابیس واقعی، مهاجرت‌ها، پرداخت، مرورگر و هاست cPanel.
- تأیید امنیتی و آماده‌بودن برای مشتری؛ هنوز مجاز به اعلام Production-ready نیست.

## استقرار
قبل از جایگزینی، از فایل‌ها و دیتابیس نسخه پشتیبان بگیرید. پس از استقرار، با محیط PHP سازگار و دیتابیس آزمایشی `php artisan migrate --force` را اجرا کنید. ابتدا مسیر `/athlete` و ورود حسابی را که مدیر ایجاد کرده آزمایش کنید. اطلاعات محرمانه را در فایل‌های عمومی قرار ندهید.
