## ۴. اصلاح امنیتی ثبت‌شده در شاخه main در 2026-11-22

### خروجی پشتیبان بدون رمزگذاری

نسخه قبلی متد `exportBackup` تنها وقتی خروجی را رمزگذاری می‌کرد که پارامتر `encrypted` صریحاً ارسال شده باشد؛ درحالی‌که کلاینت مدیریت آن پارامتر را ارسال نمی‌کرد. محتوای Backup شامل داده‌های حساس از جمله هش رمز عبور، راز TOTP، remember token، توکن دسترسی سفارش‌ها، اطلاعات تراکنش و فایل‌های خصوصی است.

اصلاح انجام‌شده:
- خروجی API اکنون همیشه از طریق `BackupVault::encryptBundle()` رمزگذاری می‌شود.
- در صورت نبود یا نامعتبر بودن `BACKUP_ENCRYPTION_KEY`، خروجی با خطای 503 متوقف می‌شود؛ داده خام برگردانده نمی‌شود.
- کلاینت مدیریت صریحاً `?encrypted=1` را درخواست می‌کند.
- URL باندل در دو ورودی HTML نسخه‌گذاری شد تا کش مرورگر نسخه قدیمی را نگه ندارد.
- دو assertion رگرسیون برای جلوگیری از بازگشت این رفتار ناامن اضافه شد.

**وضعیت آزمون این اصلاح:** تست‌های رگرسیون و PHPUnit روی MySQL 8.0.46 در CI موفق شدند؛ تست دستی Export/Restore روی محیط Staging واقعی همچنان لازم است.

### سازگاری MySQL 8 در Migration

اولین اجرای CI با MySQL 8.0.46 نشان داد که تعریف `TEXT NOT NULL DEFAULT ''` برای ستون `products.description` توسط MySQL رد می‌شود. این مشکل در Migration اولیه اصلاح شد و Migration سازگاری `2026_11_22_000001_remove_products_description_text_default` نیز برای نصب‌های قبلی اضافه شد. این اصلاح به مخزن Push شده، اما هنوز اجرای موفق Migrationها و Feature tests روی CI تأیید نشده است.

## ۵. موارد مسدودکننده Production

1. اجرای تمام Migrationها روی دیتابیس MySQL/MariaDB تازه و قابل حذف.
2. اجرای PHPUnit و `MySqlConcurrencyTest` با دو پردازش مستقل.
3. تست کامل ثبت‌نام، OTP، انقضا، محدودیت تلاش و رقابت درخواست‌ها.
4. تست واقعی ارسال پیامک و رسید MeliPayamak؛ به‌ویژه وضعیت‌های rejected و unknown.
5. تست تراکنش واقعی کم‌مبلغ در درگاه آزمایشی/پذیرنده و Callback تکراری، دیرهنگام و ناموفق.
6. تست کامل Backup و Restore روی دیتابیس و فضای فایل جداگانه؛ همچنین تأیید کلید رمزگذاری و نگهداری امن آن.
7. تست مرورگر و موبایل، نشست، CSRF، مسیرهای پنل و خطاهای شبکه.
8. نصب آزمایشی cPanel با Document Root صحیح و تأیید عدم دسترسی وب به `.env`، `storage` و فایل‌های خصوصی.
9. بازیابی سورس React/TypeScript یا بازسازی پروژه قابل Build برای توسعه بلندمدت UI.
