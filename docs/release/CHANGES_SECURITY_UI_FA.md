# اصلاحات امنیت، پایداری و UI/UX

این بسته از `ARASH_PRODUCTION.zip` ساخته شده و آرشیو اصلی را تغییر نمی‌دهد.

## امنیت و داده

- خروجی JSON-LD با گزینه‌های `JSON_HEX_*` امن شده تا محتوای مدیریتی نتواند تگ `script` را بشکند.
- checksum سطح backup اکنون اجباری و نسخه backup دقیقاً با نسخه جاری تطبیق داده می‌شود.
- backup علاوه بر checksum با HMAC وابسته به `APP_KEY` امضا می‌شود؛ فایل دست‌کاری‌شده با checksum بازسازی‌شده نیز restore نمی‌شود.
- checksum هر فایل بازیابی‌شده اجباری است و نام فایل‌های دارای traversal رد می‌شود.
- snapshot پیش از restore باید واقعاً نوشته شود و permission امن بگیرد؛ در غیر این صورت restore شروع نمی‌شود.
- خطای نوشتن فایل در restore دیگر نادیده گرفته نمی‌شود و transaction دیتابیس rollback می‌شود.
- اندازه درخواست restore به ۱۲۸ مگابایت و تعداد فایل‌ها به ۲۰۰۰ محدود شده است.
- payload همگام‌سازی مدیریت از نظر تعداد اعضا، عمق و اندازه رشته محدود شده است.
- checkout، مشاهده سفارش، دانلود و endpointهای پرتکرار public rate-limit شدند تا رزرو موجودی و دیتابیس با درخواست انبوه مختل نشود.
- شمارنده like برای هر مرورگر idempotent شد؛ like یا unlike تکراری دیگر عدد را دستکاری نمی‌کند.
- ورودی‌های installer نمی‌توانند با newline تنظیمات دلخواه به `.env` تزریق کنند و تمام مقادیر به‌صورت امن quote می‌شوند.
- setup token فقط پس از ایجاد و permission موفق lock حذف می‌شود؛ خطای فایل‌سیستم دیگر نصب را در وضعیت نیمه‌قفل‌شده رها نمی‌کند.
- Factory Reset واقعی شد: محتوای نمایشی بازنشانی می‌شود، اما داده‌های مالی، مشتری، مدیر و دانلود حفظ می‌شوند و محصولات خریداری‌شده به‌صورت امن آرشیو می‌شوند.
- هفت smoke test دائمی برای XSS، صحت، امضا و round-trip بازیابی backup، like تکراری، تزریق `.env` و بازنشانی امن داخل بسته قرار گرفت.

## UI/UX

- focus قابل مشاهده برای کنترل‌های صفحه و ناوبری صفحه‌کلید اضافه شد.
- حداقل ارتفاع کنترل‌های لمسی ۴۴ پیکسل تعیین شد.
- ورودی‌های موبایل حداقل ۱۶ پیکسل هستند تا zoom ناخواسته iOS رخ ندهد.
- پشتیبانی `prefers-reduced-motion`، safe-area پایین و فاصله از navigation ثابت اضافه شد.
- wrapping متن‌های بلند، placeholder خواناتر و حالت disabled واضح‌تر شد.
- فونت fallback فارسی و محافظت در برابر overflow افقی تقویت شد.
- تغییر routeهای SPA برای screen reader اعلام می‌شود و focus به محتوای اصلی منتقل می‌شود.
- وضعیت آفلاین با یک پیام زنده و قابل‌مشاهده اعلام می‌شود.
- لینک‌های خارجیِ بازشونده در تب جدید به‌صورت خودکار `noopener noreferrer` می‌گیرند.

## محدودیت بسته

سورس React/TypeScript و تست‌های ادعاشده در گزارش QA داخل بسته Production موجود نیستند. به همین دلیل اصلاحات UI در یک stylesheet مستقل روی build موجود اعمال شده‌اند. برای تغییر ساختاری componentها، مدیریت focus در modalها و اعتبارسنجی inline فرم‌ها، بسته source لازم است.
