# وضعیت توسعه بدنسازی — ۲۰۲۶/۱۱/۰۹

## افزوده‌شده در این نسخه
- مدل و migration برنامه تمرینی با مالکیت ورزشکار، مربی، روزها، حرکات و وضعیت پیش‌نویس/منتشرشده/آرشیوشده.
- API ایجاد حساب ورزشکار توسط مدیر (بدون ثبت‌نام عمومی تأییدنشده)، فهرست ورزشکاران، ساخت و ویرایش برنامه تمرینی.
- API ورود ورزشکار با رمز عبور، نشست جداشده بر اساس نقش، مشاهده پروفایل و صرفاً برنامه‌های منتشرشده متعلق به همان ورزشکار، خروج همراه با CSRF.
- حفظ بک‌اند Laravel و فایل‌های فرانت‌اند فعلی؛ هیچ کدی از Barbershop مستقیماً وارد نشده است.

## راه‌اندازی
1. پیش از جایگزینی نسخه، از فایل‌ها و پایگاه داده پشتیبان بگیرید.
2. نسخه PHP و افزونه‌های لازم Laravel را در هاست بررسی کنید.
3. پس از انتشار فایل‌ها، در `laravel_core` دستور `php artisan migrate --force` را اجرا کنید.
4. با نشست مدیر و `X-CSRF-Token` از `/api/v1/admin/athletes` و `/api/v1/admin/training-plans` استفاده کنید.
5. حساب ورزشکار را مدیر ایجاد می‌کند؛ ورزشکار با `/api/v1/athlete/login` وارد می‌شود و `/api/v1/athlete/plans` را می‌بیند.

## محدودیت‌ها و موارد باقی‌مانده
- فرانت‌اند فعلی صرفاً خروجی build است؛ UI پنل ورزشکار و فرم مدیریت برنامه تمرینی هنوز پیاده‌سازی نشده‌اند.
- OTP و تأیید مالکیت شماره موبایل، بازیابی حساب، ثبت پیشرفت تمرین و پیام‌رسانی هنوز پیاده‌سازی نشده‌اند.
- تست یکپارچه و مهاجرت واقعی روی MySQL اجرا نشده؛ محیط فاقد PHP DOM و درایور دیتابیس لازم است.
- تست امنیت و پرداخت و مرورگر در محیط عملیاتی انجام نشده است. این بسته برای انتشار عمومی نهایی تأیید نشده است.

## بررسی انجام‌شده
- `php -l` برای هفت فایل PHP جدید/تغییریافته موفق بود.
- `php artisan route:list` مسیرهای ورزشکار و مدیریت برنامه تمرینی را شناسایی کرد.
- `php artisan test` به دلیل نبود `DOMDocument` در محیط فعلی اجرا نشد.
