# مقایسه دو پروژه و نقشه ارتقای بعدی

## ماهیت سیستم‌ها

- Barbershop: Node.js/TypeScript، PostgreSQL، قابلیت رزرو و پرداخت و پیامک، مدیریت مشتری و تنظیمات کسب‌وکار. فایل مرجع: `Barbershop_Standalone_Latest_2026-11-10.zip`.
- ARASH Fitness: PHP Laravel، MySQL، SPA کامپایل‌شده، فروشگاه و دانلود خصوصی دیجیتال، برنامه و پیشرفت ورزشکار، تقویم مشاوره پس از این ارتقا.
- کپی‌کردن ماژول TypeScript یا SQL Postgres به Laravel مناسب نیست؛ الگوی تراکنش و قواعد دسترسی باید به‌صورت native بازنویسی شوند.

## ماتریس انتقال

| ایده/قابلیت Barbershop | تصمیم | وضعیت در ARASH 2.3 |
|---|---|---|
| جلوگیری از رزرو هم‌زمان | انتقال مدل سروری | پیاده‌سازی کد + محدودیت UNIQUE؛ تست MySQL واقعی باز |
| مدیریت مشتری و پنل شخصی | توسعه | ورزشکار، تأیید موبایل، سوابق خرید و تمرین |
| اطلاعات خصوصی حساب/IDOR | انتقال کنترل | محدودکردن پیام‌ها، خریدها و رزروها به مالک معتبر؛ Feature test موجود |
| OTP با TTL/attempt/cooldown | سخت‌سازی | رزرو DB پیش از ارسال SMS و مسیر تأیید شماره کاربران موجود |
| SMS وضعیت رزرو | انتقال تطبیقی | Outbox تأیید جلسه و گزارش unknown/sent؛ provider واقعی باز |
| پرداخت verified و idempotency | حفظ + مسیر جدید | منطق پرداخت قبلی حفظ؛ checkout جدید برای شماره تأییدشده؛ آزمون end-to-end باز |
| CRM پیگیری درخواست‌ها | توسعه | صندوق درخواست مشاوره عمومی و تعیین وضعیت |
| تقویم شمسی و اعلان یادآوری | پیشنهاد | تقویم ساده و تاریخ localized؛ یادآوری و تقویم شمسی کامل هنوز باز |
| پشتیبان‌گیری و بازیابی | توسعه | رکوردهای جدید در بسته امضاشده؛ تست restore واقعی باز |
| Owner OAuth, TOTP, recovery codes | پیشنهاد فاز دوم | هنوز منتقل نشده، نیازمند طراحی سرتاسری احراز هویت |
| رسانه‌های خصوصی پیشرفته | پیشنهاد فاز دوم | PDF خصوصی قدیمی حفظ شده؛ اشتراک فایل خصوصی مربی و ورزشکار اضافه نشده |
| نظام لایسنس SaaS آرایشگر | عدم انتقال | نامتناسب با محصول مستقل تک‌مربی |

## ایده‌های محصول با اولویت

**P0 پیش از مشتری واقعی:** تکمیل تست MySQL و تراکنش هم‌زمان، پاسخ واقعی الگوهای پیامک، تست درگاه و بازگشت تکراری، بکاپ/restore واقعی و بازبینی امنیت دسترسی/نشست؛ تکمیل بازیابی حساب ورزشکار و مدیر.

**P1 ارزش تجاری بالا:** اشتراک ماهانه/دوره‌ای مربیگری با تأیید پرداخت سرور، پرداخت جلسه رزرو قبل از تأیید، تقویم شمسی و یادآوری، فرم ارزیابی اولیه با حداقل داده لازم و رضایت صریح، داشبورد درآمد و نرخ تبدیل مشاوره به شاگرد.

**P2 تجربه کاربری عالی:** سورس قابل نگهداری React، طراحی یکپارچه موبایل و داشبورد، PWA سبک، کتابخانه حرکات با ویدیو و ابزار جست‌وجو، قالب‌های دوره‌ای برنامه و ویرایشگر ساده، نمودارهای پیشرفت بر مبنای داده‌های داوطلبانه، فیلترهای پیشرفته فروشگاه و آموزش.

**P3 در صورت نیاز بازار:** چندمربی/تیم، دعوت همکار با RBAC واقعی، قوانین تقویم چند مکان، صورت‌حساب اشتراک سازمانی، اتصال به تجهیزات هوشمند تنها با رضایت صریح.

*توجه: فازهای P1 تا P3 ایده و نقشه راه هستند، نه قابلیت تحویلی در ZIP.*
