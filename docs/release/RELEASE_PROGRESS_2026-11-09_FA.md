# گزارش پیشرفت تکمیل بدنسازی — 2026-11-09

## اصلاح واقعی این مرحله
- در `laravel_core/app/Http/Controllers/Api/V1/OrderController.php`، endpoint `POST /api/v1/customer/orders/lookup` اکنون پیش از جستجوی سفارش، مدرک دسترسی را مطالبه می‌کند؛ بنابراین بدون توکن نمی‌توان وجود شماره سفارش را تشخیص داد.
- پاسخ سفارش ناموجود و سفارش فاقد مجوز یکسان شده است (404 / `ORDER_NOT_FOUND_OR_UNAUTHORIZED`) تا امکان شمارش سفارش‌های مشتریان کاهش یابد.
- توکن هدر، بدنه درخواست و کوکی HttpOnly همچنان پشتیبانی می‌شوند؛ شماره سفارش به‌تنهایی مجوز نیست.

## بررسی انجام‌شده
- PHP lint برای فایل تغییرکرده موفق.
- چهار تست مستقل بدون دیتابیس (`tests/static_runtime_regressions.php`) موفق.
- این‌ها جایگزین تست یکپارچه روی MySQL و مرورگر نیستند.

## موارد باز
- سورس React/TypeScript در بسته Production موجود نیست؛ بازسازی فرانت‌اند و پنل ورزشکار انجام نشده است.
- ثبت‌نام ورزشکار با تأیید شماره موبایل، مدیریت برنامه تمرینی و پیگیری پیشرفت نیازمند طراحی دیتابیس، API و UI است.
- تست end-to-end پرداخت، دیتابیس، بکاپ/ریستور و استقرار روی هاست واقعی هنوز الزامی است.
- این نسخه را بدون staging و بکاپ روی سایت مشتری جایگزین نکنید.
